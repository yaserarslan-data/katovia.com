Regex Tester

Try JavaScript regular expressions on sample text in an isolated worker.

Enter a regular expression without surrounding slashes. Use JavaScript flags such as g, i and m. Results show matched text, indexes and capture groups as JSON. Limits are 100 matches, a 500-character pattern and 10,000 characters of text. If execution takes more than 750 ms, the isolated worker is terminated so the interface stays responsive. This tests JavaScript regex syntax; other programming languages may behave differently. No text is sent to a server.
