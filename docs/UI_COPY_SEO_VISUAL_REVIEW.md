## 4. CREATE reset

TR: Yeni Oluştur. EN: Start Over. A populated draft gets an inline confirmation with keep-editing/clear actions, not a modal. Reset disposes the player, clears form/questions/result/link/share state, removes only the creator draft storage key, restores one empty question, and focuses the title. Old encoded links still work. Storage-removal failures are reported accurately, and unrelated legacy keys are untouched. Pending share callbacks cannot overwrite a reset state.
