# PLAY backlog

Registry backlog: Fluid, Sand, Gravity, Neon Trails, Rain Room, Grow, Destroy This Page. Future social toys: kinetic sand, magnetic particles, liquid metal, soft body, bouncing glass, domino, falling neon blocks, melting shapes. These names are ideas, not available experiences; no route, dependency or advertised playable button is created.

Keep original Canvas/code assets and experience-level lazy loading. Evaluate reduced motion, touch/keyboard, DPR/frame budget and full disposal before adding a toy. Any dependency must have a commercial-use-compatible open-source license checked first; a paid rendering/media/cloud solution is report-only. Image export/story cards can be optional adapters consuming an experience snapshot and the existing share payload; no large export engine is added now.
