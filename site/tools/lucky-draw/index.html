Lucky Draw

Pick a random winner from a list of names or choices and keep the list on your device.

Processed locally · No input upload required

Up to 200 entries, 80 characters each. Duplicate lines count as separate chances.

    The list is saved in this browser. Reset clears the list and its local record.

    Enter one name or choice per line. Blank lines are ignored; duplicate names count as separate entries. PICK A WINNER uses the browser cryptographic random source to choose a row with equal probability. Copy the winner or remove only that winning row and continue. The list stays in this browser; reset removes the local record too. If storage is disabled, the tool still works in the current tab. This is a quick casual picker, not a certified official lottery or server record. Names are rendered as text and are not sent to a server.
