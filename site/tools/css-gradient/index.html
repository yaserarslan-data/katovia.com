CSS Gradient Generator

Choose two colors and an angle to generate a CSS linear gradient with a live preview.

Choose two colors and an angle between −360 and 360 degrees. RUN displays the gradient and generates a ready-to-use background declaration. Copy it into your CSS stylesheet. Zero degrees points upward and 90 degrees points right. A gradient downloads no image file: the browser draws the color transition itself. The color picker may look different on your device. Check contrast separately when placing text over a gradient. This tool works with your color choices and requires no external asset or account.
