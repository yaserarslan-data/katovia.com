Pixel Art Grid

Draw on an 8×8, 16×16 or 32×32 grid, fill, undo and download a transparent PNG.

Processed locally · No input upload required

Tap or drag. Focus the grid, select with arrows and paint using Space/Enter.

DOWNLOAD PNG

PNG uses a transparent background; grid lines and the cursor are excluded. Each pixel is scaled to 16 px.

Choose a grid size and color. Tap or drag with the pencil, erase to transparency, or fill a connected region. Each drawing gesture is one undo step, with the last 40 actions retained. Resizing preserves the artwork using nearest pixels and can be undone. Use arrows to select a cell and Space/Enter to apply the tool. PNG excludes grid lines and cursor; empty cells are transparent. Make small sprites, icons or mockups. Artwork stays in this tab and is lost when leaving the page, so download it first.
